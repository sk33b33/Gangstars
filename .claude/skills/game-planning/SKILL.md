# Game planning workflow

1. Read `CLAUDE.md` and the relevant game design/roadmap documents.
2. Identify the smallest playable increment.
3. State player-visible outcome, files/scenes likely affected, dependencies, risks, and acceptance criteria.
4. Check whether the task preserves the 30-house starter district and later locked turf expansion.
5. Split work into independent subtasks only where interfaces are clear.
6. Update the roadmap only after evidence confirms completion.

Never respond with a plan alone when the user asked for implementation and the repository is ready. Implement the agreed milestone.
