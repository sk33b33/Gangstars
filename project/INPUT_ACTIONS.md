# Input Action Naming

Create these actions in Project Settings → Input Map. Keep names stable so scripts and tests agree.

| Action | Suggested default |
|---|---|
| `move_forward` | W |
| `move_backward` | S |
| `move_left` | A |
| `move_right` | D |
| `sprint` | Shift |
| `jump` | Space (optional) |
| `interact` | E |
| `pause` | Escape |
| `toggle_debug` | F3 |

Use Godot's Input Map rather than hard-coding key checks in gameplay scripts.
